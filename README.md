# BlackLine Auto Center

Site static demonstrativ pentru un service auto fictiv din Constanța. Proiectul folosește HTML, CSS și JavaScript simplu, fără biblioteci sau proces de compilare.

## Deschidere

1. Deschide folderul `BlackLine Auto Center DEMO` în File Explorer.
2. Dă dublu clic pe `index.html` pentru a-l deschide în browser.

Nu este necesară instalarea unui program sau pornirea unui server local. Fotografiile și fonturile se încarcă de pe internet.

## Fișiere

- `index.html` — conținutul site-ului, formularul demonstrativ și linkurile.
- `styles.css` — paleta, aspectul responsive și animațiile.
- `script.js` — meniul pentru mobil, confirmarea formularului și aparițiile la derulare.

## Informații demonstrative

BlackLine Auto Center este un concept fictiv. Serviciile, prețurile, programul și poziția orientativă pe hartă sunt exemple create pentru prezentare, nu informații despre o firmă reală. Galeria folosește fotografii ilustrative Unsplash.

Formularul validează datele în browser și afișează un mesaj local; nu trimite și nu salvează cereri. Linkul WhatsApp pregătește un mesaj, fără un număr de telefon configurat. Pentru utilizare reală, conectează formularul la un serviciu de programări și adaugă un număr WhatsApp autorizat.
